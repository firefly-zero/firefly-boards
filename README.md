# firefly-boards

System app for [Firefly Zero](https://fireflyzero.com/) for viewing scoreboards for other apps.

## Installation

1. [Install firefly-cli](https://github.com/firefly-zero/firefly-cli?tab=readme-ov-file#installation)
1. Run `firefly_cli import sys.boards`

After it is installed, select "scoreboards" from the app menu in launcher and it will launch the scores viewer.
